# Delimiters in Prompt Engineering

## Objective

Explore how delimiters can help clearly separate instructions from the text that should be processed.

## Example Prompt

Translate the text between the triple backticks into English.

```text
Il prodotto è arrivato ieri, ma la confezione era danneggiata.
```

## Expected Output

The model should translate only the text inside the delimiters.

## What I Learned

Delimiters help structure prompts and clearly distinguish instructions from the content provided to the model.
