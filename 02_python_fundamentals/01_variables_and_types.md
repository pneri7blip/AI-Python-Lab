# 01 — Variables and Types

## Core concepts

Python variables store values.

```python
nome = "Paolo"
eta = 50
prezzo = 19.90
attivo = True
```

The main types covered are `str`, `int`, `float`, and `bool`.

```python
x = 5
```

assigns a value, while:

```python
x == 5
```

checks equality.

## Key Takeaway

`=` assigns a value; `==` compares values.
